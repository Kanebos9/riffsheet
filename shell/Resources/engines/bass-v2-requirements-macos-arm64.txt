# Riffsheet one-click install lock: instrument-agnostic-amt (bass-v2) on macOS arm64.
#
# EVERY package, including every transitive one, is pinned to a version AND to
# the sha256 of the exact artefact. The installer runs pip with --require-hashes
# against this file, so a package that has been re-uploaded, a mirror serving
# something else, or a dependency that moved underneath us all fail loudly
# instead of being installed. Without this, one-click install would be an
# unverified network install sitting next to a sha256-pinned download.
#
# Generated from pip's own resolver, not by hand:
#   pip install --dry-run --report r.json \
#       "torch==2.13.0 torchaudio==2.11.0 einops==0.8.2 numpy==2.2.6 pretty_midi==0.2.11.post0 scipy==1.15.3 soundfile==0.14.0 tqdm==4.70.0" \
#   then one 'name==version --hash=sha256:...' per entry of r.json's install list.
#
# The file is per platform because a wheel hash is per platform. A platform with
# no lock file here cannot one-click install: EngineInstall::planFor() says so and
# the card falls back to the guide rather than guessing.
#
# torch is the stock PyPI build. Upstream's requirements.txt asks for
# torch==2.7.0+cu128 from the CUDA index, which has no macOS wheel at all; the
# audition proved stock 2.13.0 runs this model on this machine.
#
# Resolved and installed on 2026-08-10 with pip 26.2.1 / CPython 3.10.11.
